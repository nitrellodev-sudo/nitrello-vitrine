# Audit SEO complet · nitrello.com · 06/08/2026

Audit réalisé avec le skill **seo-mastery** (plugin MCPmarket, `~/.claude/plugins/mcpmarket-me/skills/seo-mastery/`), en croisant le site en production et le code source du repo `~/Projets/nitrello-vitrine`. Audit seul : aucune correction appliquée, aucun commit.

## Synthèse

Le site est techniquement sain : HTTPS avec redirection 308, robots.txt propre, sitemap dynamique, une vraie 404, un seul H1 par page, toutes les images avec alt, TTFB excellent (90 à 230 ms, cache Vercel HIT sur le point de présence de Paris). Le vrai problème n'est pas technique : **la prod sert encore l'ancien positionnement** ("Ton idée devient une application", cible "startups") alors que la refonte metadata alignée sur l'offre 2026 est déjà écrite en local, non commitée. S'y ajoutent un certificat SSL cassé sur www, un doublon de marque dans tous les titles, et l'absence totale de données structurées LocalBusiness pour un indépendant qui vise les TPE/PME locales.

## Points solides à préserver

- Redirection HTTP vers HTTPS en 308, HTTPS valide sur l'apex
- robots.txt minimal et correct, sitemap déclaré dedans
- Sitemap dynamique branché sur Supabase (les futurs articles s'ajoutent seuls)
- Vraie page 404 (HTTP 404, pas de soft 404)
- Un seul H1 par page, hiérarchie H2/H3 fournie, lang="fr", viewport correct
- 0 image sans alt sur tout le site, WebP partout, lazy loading présent
- Article de blog exemplaire : canonical, og:image dédiée, JSON-LD triple (BlogPosting, BreadcrumbList, FAQPage)
- TTFB 90 à 230 ms avec cache CDN Vercel (x-vercel-cache: HIT)
